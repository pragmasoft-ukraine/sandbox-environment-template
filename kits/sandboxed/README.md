# Sandboxed mixin kit

## For Docker sandbox kit spec V3

## Best-practice rules for an agent running inside a sandbox.

Manifest-only mixin. Its single capability adds agent context; it installs nothing.

Mixin context is progressive disclosure: CLAUDE.md gets a pointer, the rules live in
~/.claude/kits-agent-context/sandboxed.md. The description is therefore written as a
read trigger.
